# \# Игра Камень-Ножницы-Бумага

# 

# \## Описание

# Это консольная игра "Камень, Ножницы, Бумага", написанная на языке Python. Программа позволяет пользователю сразиться с компьютером, отслеживает счет побед и сохраняет итоговый результат в текстовый файл.

# 

# \## Как играть

# 1\. Убедитесь, что у вас установлен Python 3.x.

# 2\. Запустите игру командой: `python game.py`.

# 3\. Вводите ваш выбор: `rock` (камень), `paper` (бумага) или `scissors` (ножницы).

# 4\. Чтобы выйти из игры и сохранить результат, введите `q`.

# 

# \## Функциональность

# \- Случайный выбор хода компьютером.

# \- Валидация ввода пользователя (защита от опечаток).

# \- Система подсчета очков в реальном времени.

# \- Сохранение итогового счета в файл `scores.txt` при выходе.

# \- Объектно-ориентированный подход к управлению счетом.

# 

# \## Требования

# \- Python 3.6 или выше.

# \- Дополнительные библиотеки не требуются (используется стандартный модуль `random`).
